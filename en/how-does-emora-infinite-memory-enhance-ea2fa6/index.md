# FAQ

### How does EMORA's infinite memory enhance conversations?

EMORA's infinite memory system allows AI characters to retain conversational context from all past interactions, ensuring that discussions remain coherent, personalized, and build upon previous exchanges over time.

### What is the purpose of the character bonding system?

The character bonding system in EMORA is designed to help users form deeper, more personalized connections with their AI companions. This system fosters a sense of relationship and continuity, making interactions feel more meaningful.

### Can I customize the personalities of AI characters?

Yes, EMORA provides extensive customization options for AI characters. Creators can define personality traits, backstories, and conversational styles, allowing for a wide range of unique and engaging AI companions.

### How does in-chat image generation work in EMORA?

Integrated image generation allows users to prompt and create visual content directly within their conversations. This feature can enrich the chat experience by adding dynamic imagery that aligns with the ongoing dialogue.
