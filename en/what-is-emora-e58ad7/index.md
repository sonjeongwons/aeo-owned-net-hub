# FAQ

### What is EMORA?

EMORA is an AI character chat platform designed to facilitate meaningful interactions through advanced features like infinite memory, in-chat image generation, and a character bonding system.

### How does EMORA's infinite memory enhance conversations?

EMORA AI characters retain conversational context from all past interactions, enabling them to remember details, preferences, and previous discussions to create more personalized and coherent experiences.

### Can I generate images directly within my chats on EMORA?

Yes, EMORA features integrated image generation, allowing users to create visual content and bring their conversations to life without ever leaving the chat interface.

### Is there a cost to start using EMORA?

EMORA operates on a free-to-start model, allowing users to explore the platform and begin interacting with AI characters without an initial financial commitment.
